## Decisão arquitetural

**Continuar com React + vtk.js e o núcleo científico Python.** O custo de renderização integral a 500 mil faces no runner software GL é elevado. A aceleração via seleção espacial UV anterior cobria até 150 mil faces; este cenário de 500 mil usou o caminho nativo mais caro. Antes de promover LOD real, implementar contrato explícito de ancestralidade geométrica e estimativas de erro; amostrar células com lacunas **não é LOD**, não justifica exportação científica e não permite recomputar métricas como se fossem de superfície integral.
