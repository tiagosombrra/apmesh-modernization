# Mesh Studio R2.5 — repeatable graphics navigation and source-exact partial preview

**Date:** 2026-11-16. **Status:** experimental gate; do not infer scientific generator performance.

This phase measures short scripted orbit trials, the synchronous native picker call, and
Chromium JavaScript heap observations in a single hosted software-rendered browser.
It **does not** measure real GPU-present FPS, task completion, total browser RSS, GPU
memory, Windows WebView2 or independent scientific runs. No performance threshold or
cross-host claim is warranted based on one runner.

A new `sourceFacePreviewPair` creates a sparse display subset of original QUAD/TRI
faces (with holes). It copies no source vertex coordinates, joins no faces, and maps
every displayed cell to exactly its original source face ID in both XYZ and UV. It
rejects inconsistent source SHA, source owner descriptors and face correspondences.
The preview carries explicit flags: `is_lod=false`, `complete_surface=false`,
`scientific_quality_comparable=false`; do not describe it as a proper geometric LOD.

Run normal Playwright contracts to check the mapping at 50k, then opt into a
separate CI job for 500k with three scripted 24-frame orbit samples per viewport
at original and sparse-subset visibility. This controls scene and browser version,
but the observations are not independent GPU replicates. Measure source-face
picking in the full view and CDP heap at three checkpoints. Persist JSON under
`test-results/`, and upload it as a required CI artifact. For each result record
its exact commit, runner and original-source classification.

Acceptance is bounded to: strict contract preservation, regression success and
a real Chromium receipt of controlled graphics operations. Native 500k APMesh
models, multichart correctness, full fidelity LOD error bounds, user latency and
Windows GPU remain open.
