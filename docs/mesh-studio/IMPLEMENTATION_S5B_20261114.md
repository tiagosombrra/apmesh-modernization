# S5b — Comparative figure foundation and experiment history integrity

2026-11-14. Scope: **visual publication infrastructure and deterministic mock
inputs**, not scientific comparison results. Branch:
`feature/mesh-studio-fixture-first-20261114`.

## Implemented

1. `experiment_history.py` implements a strict, bounded, standard-library-only
   reader for the repository's eight invented history events. The parser
   rejects the header mismatch, invalid nonfinite values, duplicate/missing
   epochs, invalid elements/status, missing accepted initial state and any row
   falsely claiming non-synthetic origin. Accepted-error increases are retained
   instead of being smoothed away.
2. `multi_model_publication.py` exports a three-panel TRI / QUAD-TRI /
   all-QUAD **synthetic pedagogical gallery** and a separate two-panel
   synthetic epoch/error/time figure. Exports use independently auditable
   vector SVG/PDF at 182 × 112 mm, with a reproducible recipe, CSV tables,
   output SHA digests and a two-column LaTeX include file.
3. The real controlled P1 OBJ is independently qualified by its original
   Bezier control-net oracle **only to keep P1 outside** the factorial
   adaptive sizing comparison. No visual synthetic-vs-real numerical ranking.
4. `publication._scan_pdf` now has a bounded per-figure drawing threshold,
   retaining the existing 70-drawing default for the real P1 figure.

## Data and scientific restrictions

The three source fixtures represent **distinct synthetic geometries and
resolutions**; each figure panel has an independent extent. Hence the figure
is not a fair cross-method benchmark. The original history CSV contains
fabricated values lacking source model identities and common metric
certification; these values may be shown for parser/plot testing only.

The scientific 3×2 topology × sizing matrix remains `NOT_AVAILABLE`, with
actual controlled P1 fixed16/vertex_mean recorded separately. A true source
all-QUAD adaptive and anisotropic study is not asserted. Actual rejection
records from the generator cannot be inferred from an OBJ alone.
