## Falsifiable source-code semantic claim

The original C++ `src/crab_mesh/aft/advancing_front.cpp` at Git blob `1bd430d1bd1079e6f55f3bc7488ff9313e4bb82b` implements `ComputeStageFaceStats`. It classifies generated **stage-1 post-AFT** TRI faces by original mesh-edge identity: boundary if any of the three edges has only one incident face; otherwise it classifies a face as **transition** iff `h_min > TOLERANCE_AFT && h_max / h_min > 1.8` (edge length aspect), otherwise as internal. `run_stats.transition_element_ratio` is this **count/total faces**. It is NOT the fraction of faces lying in a geometrically defined near-boundary transition band. An elongated triangle with no boundary edge is counted as transition irrespective of geometric distance. The original C++ `src/adapter/adapter.cpp` at blob `78f821411f33a8ca7594c8e357bbe4a79e5d33f9` uses the ratio (post AFT stage 1), along with `internal_element_ratio`, in `IsTransitionUnderresolved`.

Separately `Adapter::ComputeRegionalPatchStats` classifies **generated post-AFT + smoothing domain geometry** by boundary edges and, for nonboundary faces, `FaceBoundaryDistance(face) <= transition_band_width || FaceAspectRatio(face) > 1.8` with `transition_band_width=clamp(target_patch_h*1.75,0.08,0.32)` when `target_patch_h>0`. Its `boundary_elements/transition_elements/interior_elements` are **three integer counts from this different spatial-or-elongated classifier**, not the original AFT stage-1 shape-only counts. Only the AFT ratio participates directly in the original `transition_underresolved` Boolean. Even the regional transition count includes interior elongated faces and thus does not by itself prove a continuous spatial band, no physical curve welding or quality.

The original study's earlier descriptive phrase *insufficient physical transition band* therefore overstates what the gating data independently establish. The preregistered R2.7.29 question is: **How different are those two quantities in the genuine per-local-attempt original C++ Eistute CSV, and which exact code predicates determine the late step-4 gate?**
