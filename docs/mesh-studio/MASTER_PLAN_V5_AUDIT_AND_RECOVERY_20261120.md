## 1. Executive decision

**Stop the unbounded sequence of instrumentation-only milestones.** Preserve the successful R2.7.12–R2.7.34 scientific receipts, but make an *independently reviewable, usable research Studio vertical slice* the primary engineering objective. Run source-native science and finite targeted experiments **only when they resolve a named product or accepted-epoch blocker**. Maintain two separate, non-interchangeable tracks:

- **Product track (Studio):** trustworthy imported source, real XYZ/UV viewer, readable original source/acceptance status, independent metrics, reproducible journal-ready vector figure/export, installation, access, memory and speed.
- **Scientific research track (original TRI / QUAD+TRI):** source-original accepted epochs and curve/patch identity, topological node ownership, AFT transition classifier semantics, original acceptance gates, element ancestry and mathematical geometry error. A rejected local Adapter TRI is a diagnostic candidate, **not a globally accepted epoch**. Scientific policy alterations require adviser-reviewed preregistration in the appropriate research branch.

Previously delivered and **not to be incorrectly relisted as missing**: a genuine React/TypeScript/vtk.js/FastAPI dual-view prototype, SHA-pinned real P1 and staged candidates, headless Python quality/vector outputs, deeply immutable imported metadata, real-patch sidecar schema support, typed V2 transport, source-ID-preserving picking, accepted source-native TRI step-1 Eistute/Book viewer bundles, 510 Linux and 510 Windows scientific software tests, 55 Chromium tests, opt-in diagnostics and original C++ R2.7.34 source curve/fan evidence. These are **qualified only at their documented respective scopes**, not a released Studio or qualified geometric LOD.

## 5. Technical/scientific metrics and evidence gates

A result is **PASS** only when its own test executed on the exact source commit with raw reproducible input and independent negative controls; **PARTIAL** when limited to a clearly labeled source/process or sampled subset; **BLOCKED** for missing mandatory causal input/accepted epoch; **NOT_EXECUTED** when hardware, test or source is absent; **FAIL** when an executed required control contradicted the claim. Tests passing do **not** imply all other gates passed.

Mandatory delivery ledger per experimental study:

- Exact Git commit, toolchain, independent original source C++ blob, model and config SHA, process/attempt/acceptance identities, full method/gate version and mathematical metric definitions.
- Number of **genuinely committed** original TRI/mixed epochs vs number of local Adapter returns/attempts; full accepted/rejected/rollback counts; source patch and curve fan counts, original native node versus XYZ correspondence distinction.
- Original native scientific output SHA/size classes and full raw source report/NDJSON when needed; artifact ZIP SHA, GitHub run/artifact IDs, durable Drive archive SHA/readback **without leaking private links**.
- Negative controls for forged source/CSV/face/curve identity, altered same-path OBJ, unsigned/synthetic model passed as real, missing/expired artifact, unsupported QUAD, nonfinite UV/XYZ, duplicated logical source IDs and false physical welding.
- Performance must separate original C++ generator CPU, Python parsing/quality cost, Web UI interaction, Worker query/IPC, VTK render/present, memory and physical hardware. Never label JS CPU duration GPU present or synthetic 500k as a real native mesh.

**Independent research branch constraints:** QUAD-related two-accepted-mixed-epoch design is tracked under [QUAD issue #221](https://github.com/tiagosombrra/apmesh-modernization/issues/221), not automatically closed by original TRI R2.7.x or Studio view tests. The production modernization Stage 3 plan remains separately controlled by docs/MODERNIZATION_PLAN.md and docs/PROJECT_STATE.md.
