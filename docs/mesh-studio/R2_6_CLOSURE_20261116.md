## Original face lineage contract

`sourceLodLineage.ts` records deterministic exact source-face partitions using CSR offsets plus original uint32 source IDs. The verifier rejects foreign identifiers, duplicate ownership and missing faces. It cannot, and does not, certify coarse mesh geometry, patch boundaries, manifoldness, metrics, Hausdorff error or anisotropic properties. Synthetic-only guard explicitly rejects any real source SHA, so this result cannot be presented as an APMesh generator or scientific surface result.

`sourceFacePreview.ts` remains an explicitly *partial* preview with holes, and the R2.6 `Bench.tsx` UI includes a separate full partition audit button. No real mesh source IDs are welded or reinterpreted.
