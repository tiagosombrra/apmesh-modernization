# Mesh Studio R0/R1 — immutable scientific metadata and web-first prototype

2026-11-15. Parent Studio commit: aefa0243b71de93956b3b9459948e9e093f45f21.

## R0 changes

- Source curve metadata now uses recursively immutable `MappingProxyType` and tuples;
  `semantic_metadata_sha256` is derived from canonical JSON separately from exact
  file-byte SHA-256. The 191 original scientific tests must stay unchanged.
- Real source patch sidecars use explicit `apmesh.meshstudio.real_patch.v1`,
  original source OBJ SHA-256, model SHA-256, generator commit, patch descriptors,
  face-to-patch IDs, original face indices, UV per corner and shared-curve
  incidence. Synthetic V1 sidecars retain their original semantics.
- An imported real sidecar is **a claim**, not proof of a real generator
  measurement. No new acceptance epoch or globally welded source topology
  is inferred from metadata or coincident coordinates.
- `topology_audit` operates on explicit patch identities when present, and
  otherwise preserves its original OBJ group warning. Source IDs are never
  guessed from color/element group or spatial proximity.
- The read-only local FastAPI service accepts only five already-known physical
  OBJ baselines (P1, band, west, north, both), rechecks SHA-256 on each request,
  serves both coordinate spaces and original face IDs, returns Python-owned
  quality results, and refuses arbitrary paths/foreign models.

## R1 web-first vertical slice (source implementation, NOT browser qualified)

React 19 + TypeScript + Vite 8 + vtk.js: model picker, dual XYZ/UV geometry,
original face ID picking, TRI/QUAD visibility, edge toggle, source status,
read-only Python quality inspector. No algorithm rewrite in the browser.

**Acceptance pending:** dependency install/npm build, vtk.js browser rendering,
real mouse cell picking, camera persistence across filters, real Chromium
Playwright and Windows/Linux GPU. This environment has Node/TypeScript
parser but cannot resolve registry.npmjs.org (EAI_AGAIN). The dedicated
Studio GitHub Actions workflow requests these tests on standard Linux runner;
its result must be checked before claiming R1 qualification.

## Scientific caveats

The five source meshes are one controlled Bezier patch evaluation, not five
statistically independent experiments. S5d staged meshes remain unaccepted;
`accepted_adaptive_epochs=0`. All-QUAD, real tensor-driven anisotropy,
source-global nonmanifold welding and native runtime event tracing remain open.

## Non-goals and isolation

Only `tools/mesh_studio/`, `docs/mesh-studio/` and the new branch-scoped
`.github/workflows/mesh-studio-validation.yml` were modified. Production
`src/`, `include/`, `quad-templates`, `main` and generator scientific
algorithms remain untouched. No automatic merge, release or installer.
