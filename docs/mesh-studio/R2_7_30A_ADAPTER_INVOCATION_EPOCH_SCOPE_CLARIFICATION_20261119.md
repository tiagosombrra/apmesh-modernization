# R2.7.30A — distinguish global outer epoch from local Adapter invocation

**Scoped preregistration clarification, before native R2.7.30 observer execution.** The original R2.7.30 protocol is retained byte-for-byte and all source original scientific controls stay unchanged.

The original `GeneratorAdaptive` assigns `current_research_outer_={session,++epoch,global_retry}` **once at each GLOBAL candidate retry**, and passes this namespace to its Adapter. Within the same global epoch, `generate_patch_mesh(...,local_retry)` may call `Adapter::AdaptDomain` **more than once for one CAD patch**, including source original step1 local `retry=0` and `retry=1`, and later structural repair candidate invocations. Therefore a `LocalSelectionEvent` carries TWO distinct retry dimensions: `event.attempt.outer.global_retry` versus `event.attempt.retry_index`. **They must never be forced equal**; such a test would reject legitimate native C++ observations and miss authentic local structural repairs.

Because the same original outer epoch and patch can encompass multiple Adapter invocations, **`(outer_epoch,patch)` is NOT an identity-complete local selection group**. The actual `PublishLocalSelections` callback emits a contiguous group of local attempts, in chronological order with local attempt indices 0..N, **after** each Adapter invocation completes. A separate `adapter_return_index`, based on the verified contiguous observer group order and independently matched complete original CSV group order, identifies a selected local return. One `SelectedForAdapterReturn` is required **per verified invocation group**, not per `(outer_epoch,patch)` pair. The group order index is a read-only replay witness, not a new original numerical identity or a global commit.

Revised test discipline: emit and preserve both retry dimensions, require globally nondecreasing epoch and bounded retry fields, join all group-local events in exact chronological order to the independently source-verified complete CSV candidate groups and equal generation statuses, reject missing/extra/ambiguous per-group events, and preserve repeated outer `(epoch,patch)` groups as genuine. Reconstruct a selected local numerical metric **only when its full group is matched**, and never equate it to an accepted native TRI epoch.

This is a source-grounded correction of scope terminology only. No policy, geometry, source executable, article configuration, original dataset or LOD acceptance is changed. R2.8 BLOCKED; PR #239 DRAFT.
