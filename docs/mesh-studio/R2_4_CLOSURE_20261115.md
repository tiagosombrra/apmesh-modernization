## Concrete source changes

1. `scene_transport_v2.py`: V2 little-endian, CRC32-guarded source-SHA-bound Float32 display stream; chunks capped at 64 KiB by default, 32 MiB total response ceiling; prevalidation before sending. This avoids one *full extra transport byte array*, but does **not** eliminate the Python source-model or `geometry()` allocations.
2. `web_api.py`: read-only `/api/v1/models/{id}/geometry.v2.bin` endpoint. Curated SHA-bound source catalog remains the only supported input, no arbitrary path upload.
3. `binaryGeometryV2.ts`: strict typed views into aligned binary `ArrayBuffer`, CRC32 verification, original source face permutation and native TRI/QUAD preservation; no nested points/cells are materialized.
4. `meshAccess.ts`, `geometry.ts`, `Viewer.tsx`, `uvSpatialIndex.ts`, `App.tsx`: typed/native interoperability; stable IDs in XYZ and UV, safe UV fallback, no automatic welding; the original V1 endpoint and decoder remain for compatibility.
5. `syntheticPacked.ts`, `Bench.tsx`: a synthetic 500k two-view fixture with shared native QUAD connectivity and no 500k nested face arrays per view. The all-zero SHA is explicitly **not an APMesh source hash**.
6. New Python and Chromium unit/adversarial tests reject corrupt CRC, truncated payload, foreign original source ID and inconsistent arities.
7. Diagnostic-only 500k workflow with explicit environment variable and reproducible receipt; regular CI does not turn the 500k stress into a silent performance promise.

## Research constraints and stop/go

- No proof yet of the QUAD generator with 500k native real elements; source model remains P1 plus staged candidates.
- The V2 original OBJ SHA belongs to the input source, and CRC32 only checks transport integrity. Neither certifies downstream GPU floating-point precision.
- No scientific global patch/curve ownership is deduced by the graphics frontend.
- No adaptive epoch is accepted; synthetic 500k is **not** all-quad generator output.
- Next R2.5: repeated controlled navigation/picking and memory studies with synthetic and **independent real source models**, explicit hardware environments; LOD only after exact original-face provenance mapping is designed.
- Native Windows GPU/ViewWeb2 certification and signed desktop distribution remain open.

**Git/CI audit:** branch-scoped changes only; no `main` or QUAD scientific release merge, tag, or installer.
