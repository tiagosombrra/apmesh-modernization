## Root cause and ownership design

CalculateAreaTriangleMedio allocated a MeshAdaptive without an owner and returned
only a scalar area. The final physical graph remained retained, the patch pointed
at that temporary graph, and fresh curve samples had no caller cleanup. Exceptions
also lost the outer mesh before adoption or after replacement.

The actual public member now lives in src/estimate/triangle_area_estimate.cpp.
Its MeshAdaptive has automatic lifetime. Each BuildInitialEstimateSubMesh result
keeps its unique owner until InsertSubMeshAdaptive consumes it on entry. The
selective EstimateMeshScope restores the preceding patch observer and clears all
owned aliases before deleting each fresh sample once, without allocation. Declare
the physical mesh first so scope teardown precedes physical graph destruction.
Those physical nodes are independent copies, not owners of the curve samples.

The scope is extracted from the qualified count caller only after checking that
both use the same actual factory, fixed four-curve topology and publication rules.
Initially nonempty point lists and all parameter lists remain borrowed. Only fresh
samples in initially empty lists enter this scope's ownership. Shared corners and
repeated curve incidences are deduplicated without a temporary allocating set.
All 159 count outcomes and 42 unchanged allocation calibrations are rerun against
the shared scope. No shared_ptr, production callback interface or retry is added.
