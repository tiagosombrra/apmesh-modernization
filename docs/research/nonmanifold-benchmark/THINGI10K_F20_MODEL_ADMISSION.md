## Why a new gate is necessary

The 23 literature-linked Thingi10K mesh IDs come from **two methodologically different source cohorts**:

- 12 examples from **Pietroni et al. (QuadWild, SIGGRAPH/TOG 2021)**, which publish output QUAD counts and geometric quality metrics. The original method remeshes **triangle surfaces**.
- 11 examples from **Badia et al. (JCP 2022)**, which supply STL geometry/testing examples without the same published QuadWild QUAD output oracle.

An original STL is **not** an APMesh four-sided bicubic Bézier domain. A meshing result from a reconstructed patch decomposition is not automatically a matched-input method comparison. Nor does a triangle mesh with incident edges shared by >2 facets establish an intentionally authored CAD non-manifold junction.

## Uncrossed admission gates

1. G1 — Provenance and asset-specific permissions, including both source and derived mesh. A GitHub mirror or paper citation is not an independent permission grant.
2. G2 — Independent raw source topology (incidence, vertex links, connected components, boundary, orientation, degeneracy), distinguishing intentional junctions from defects.
3. G3 — Reproducible source-conforming four-sided Bézier decomposition with explicit shared boundary identities and error certification; not only a triangulated STL import.
4. G4 — Accepted APMesh runs (supported TRI, QUAD or QUAD-dominant modes), source/patch connectivity, baseline versions, timings and repeatability.
5. G5 — Fair reference pair, comparable preprocessing, exact metric definitions (SJ, AD, ED and irregular vertices), same input domain or clearly stated non-equivalence.

No gate can be overridden by a synthetic test count or a necessary Euler invariant alone.

The script rejects duplicates, missing cases, contradictory source Euler/genus/hash, changed status claims, false published Euler counts and unsupported rights or execution promotions. **22/22 synthetic offline tests passed** locally; the original published/static evidence was read independently from the repository, but no original mesh was downloaded or regenerated by this phase. Data changes require a new evidence-specific schema, not merely changing `NO` to `YES`.
