# Candidate selector for a native template parent grouping

Recorded 2026-11-23 Fortaleza. Use archived native front and seed
data from the [Ribbed single-parent trial](RIBBED_SINGLE_PARENT_TEMPLATE_TRIAL_20261123.md)
and the original Bezier Step 3. This is a read-only selector
evaluation. No new generator policy is adopted. The
[receipt](evidence/MIXED_TEMPLATE_GROUP_SELECTOR_20261123.json)
records all identities and the primary witnesses.

## Selection available for a bounded native comparison

Start at the worst physical minimum-angle TRI of a generated
mesh before smoothing. The rule is eligible only if the TRI
touches the contour at exactly one vertex and its opposite side
is an exposed template edge facing that contour vertex. Find
the parent by native dyadic boxes. Require four leaf siblings
with actual seed output. Independently reconstruct what the
existing template cycles and area centroids would emit after
grouping them. Preserve edge-neighbor balance and the existing
contour clearance. A trial may attempt only that one group.

At the original short edge, prefer strictly smaller mismatch
between the predicted replacement edge length and the physical
median edge length of the original TRI. Measure in XYZ, and
preserve a group whenever the exposed side would be unchanged.
Conservatively veto the group if an active residual size
reduction lies in the group or in a neighboring cell whose
template would change, including capped requests. This veto
uses the actual request sites and includes boundary ties.
If any condition fails, leave the entire tree alone. Do not
continue down the list to a less limiting angle. These are
proposed experimental rules and not adaptive acceptance.

## What the archives show

- **Original Ribbed control.** Starting at the worst 6.33-degree
  TRI identifies the same parent used in the successful native
  trial. Its template half-edge length rises from 0.12500 to
  0.25000. The estimated ratio to the TRI median edge length
  falls from 8.53 to 4.27. No active request is in the group
  or affected neighbor boxes. This independent selection binds
  to an already measured native outcome for this parent.
- **Ribbed after one grouping.** The worst 6.86-degree TRI
  selects a different parent on the opposite side. The double
  edge is predicted to reduce that same ratio from 8.31 to
  4.15. Actual front and final element quality after grouping
  this second parent are unmeasured.
- **Original Bezier Step 3.** At the limiting 1.42-degree TRI,
  the existing T6 pattern retains the exact 0.04731 edge.
  Its ratio stays 14.15. The selector returns no action on
  this source. This agrees with the prior template audit
  of single-block grouping.
- **Resolution preservation controls.** Replay the existing
  residual size requests on the Bezier Step 3 archive. Of
  24 geometrically eligible face observations, eight are now
  vetoed (these need not be distinct parents). For example,
  one neighboring cell has a reduction to 0.17610 model
  units and vetoes a proposed group near a 3.45-degree TRI.
  A separate injected smaller-request control at the proven
  Ribbed parent suppresses exactly that primary choice.

The tests distinguish a projected size improvement from actual
mesh quality. There is no guarantee that a projected ratio
change will improve the worst TRI or preserve error after
advancing front. The conservative request veto is intentional
for this proposed comparison. The Bezier requests are independently
replayed rather than archived native execution on that stage.
