# Native batch of disjoint short-base transition repairs

The approved trial applies the two [cross-model projections](CROSS_MODEL_SHORT_BASE_TRANSITION_20261126.md)
to their exact development controls. [Draft PR 298](https://github.com/tiagosombrra/apmesh-modernization/pull/298)
adds the opt-in native plan command `replace_seed_layers_after_smoothing`
at `acdcc66af6b5254cc00b5c7b1e7f012f25b283b5`. Its header carries
the existing face budget and physical floors, followed by the number
of regions. Each region carries the existing site binding, original
face witness, and replacement layout.

One batch runs after the original guarded smoothing. All regions
validate against the same original topology and birth sites. The
existing one-template-layer and directed local boundary checks apply
to each region separately. Repeated original face indices across
regions refuse the whole batch. The union has one face budget and
protects requests incident to any old region at birth or after
smoothing. The native path retains shared, contour, and previously
introduced vertices. It validates the complete topology, orientation,
overlap, local shape, and physical sizing in a temporary candidate.
It commits the topology after validation and the retained-site
journal succeed. The existing owning native path verifies the
predecessor graph and archive on both successful staging and refusal.
The existing early and post-smoothing single-region plans keep
their syntax and mode. The default TRI path is unchanged.
