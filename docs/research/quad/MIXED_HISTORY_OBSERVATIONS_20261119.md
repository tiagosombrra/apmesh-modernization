## Capability and contracts

The report previously attached the original TRI curvature error only to accepted
source stages. Rejected attempts had a blank even when their original CSV
contained the measurement. The tool now exposes the logged value after matching
the archived TRI node/element counts and checking finiteness. This remains an
original TRI attempt value; it is never labeled the mixed global curvature error.
CSV count matching is the existing association contract, not a new independent
proof of the native curvature formula or a native CSV-to-OBJ content signature.

Every retained source stage now has a full step/epoch/retry/domain identity,
accepted/rejected reason, previous accepted source identity, retained accepted
source identity, and links to both actual TRI and mixed reconstruction hashes.
Existing geometry-error and quality observations are attached to these links.
Node/element changes and sampled source-area RMS changes compare against the
previous accepted source's reconstruction. A rejected attempt never replaces
that comparison base. Source acceptance never implies mixed adaptive acceptance.

New history.csv and metrics.json bindings retain the original manifest order.
Markdown error/quality tables expose epoch, retry and source acceptance. Existing
metrics/elements exports remain available. Duplicate numeric stage identity,
invalid source outcome/order, incomplete or foreign observations and mismatched
or nonfinite rejected TRI metrics are refused. Missing native metrics remain
explicitly unavailable. Only exported stages are covered; internal retries absent
from the archive are not reconstructed, reordered or fabricated.
