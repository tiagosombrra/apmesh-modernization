## Comparison domain, sources and scientific limits

All candidates must be generated by actual native `Generate` /
original `OwnedQuadAftFront` and independently audited as actual OBJ
before admission to this *read-only comparison*. No synthetic proposal
and no rejected physical QUAD/AFT output is ranked as a mesh.

The source Bezier metric samples **identical 4096 UV midpoint sites**
across first staged band, west, north and both. Every candidate is
independently checked for real source XYZ, 16 original source-boundary
edges, physically mapped facet orientation, typed QUAD/TRI elements,
positive four-corner QUAD Jacobian and warpage, and genuine area of
QUAD polygons in UV. Compare *both* QUAD UV area fraction and physical
element **count**: the former measures space covered; the latter is
sensitive to local refinement and cannot substitute as area dominance.

The strict source-specific comparability assumption is that the same
parametric source, sampling pattern and Bernstein control net are used
across candidates. Minima can mask local deterioration: no claim is
made that every face quality is unchanged or that a PDE solution error
has decreased. These are discrete approximation diagnostics, not a
continuous supremum/energy norm or scientifically approved global
adaptive stopping rule.

## Two explicit, different Pareto profiles

Both profiles minimize max XYZ source error, source-area-weighted
sampled RMS, physical node count and **total** face count; both
maximize physically measured QUAD UV area and the two validated
minimum QUAD quality witnesses.

- `uv_area_profile` treats spatial QUAD coverage as the QUAD objective.
  Here **north weakly dominates west**: same 125 faces and 37.5% QUAD UV,
  less RMS error and two fewer nodes, with equal recorded global minima.
  Non-dominated candidates are **first band, north, both** because the
  first band is cheaper and both covers more area with lower sampled
  error but a greater element cost.
- `quad_count_profile` adds a separate objective to maximize number
  of actual quadrilateral faces. West has 75 vs north's 71 QUADs
  despite equal UV area and total faces. Consequently **all four
  remain non-dominated** under this objective system.

A Pareto dominance relation is **not** an approval to accept any of
these as the new `Patch/SubMesh` owner. Both objective sets are
bounded diagnostic perspectives; actual scientific decision must
pre-register a justification for the quality/error/cost objective and
test sensitivity to source resolution and weighting.

## Engineering gates and exclusions

The independent `tests/quad/independent_pareto.py` takes only
real measured objective dictionaries, rejects missing, foreign,
inconsistent, nonfinite or invalid counts, and emits both deterministic
non-dominated fronts and per-candidate dominators. Six adversarial
standalone Python tests are explicitly executed by the actual QUAD
application regression on Linux/Windows/sanitizer. The primary
regression computes its own objective records from the real previous
and three current OBJ metrics; the reference fixture is a **test
control, not** a replacement for running native meshes.

Required exact SHA Linux GCC/Windows MSVC real QUAD/native application,
Linux ASan/UBSan/leak, original Eistute/Book frozen TRI parity,
85 CTests/527 Python and source-specific negative controls.
