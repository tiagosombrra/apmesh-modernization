## Fixed catalog and completion rule

There are seven work packages with four named items each: **28 work items**.
F8 is their final integration/closure audit. This is a finite deliverable catalog,
not a claim that unknown defects take a fixed time or that every item is executable
now. Each item ends with measured evidence or an explicit unresolved dependency.
A blocked disposition is an actionable stop, never successful qualification.

Only one item is active. Reuse an existing result after matching its relevant
source/build/input/oracle/instrument/binary identities. Do not repeat a campaign
to fill a table. New instrument work requires the named missing observation below.
Code changes require an admitted supported defect. Group related owner/caller
repairs; formatting is checked before compiling and qualifying final images.

A package closes only when all four exits are satisfied, dependencies are met and
its exact-head/main gates pass. Retained evidence needs applicability review;
its presence alone is not a new qualification. A new supported defect becomes a
blocking finding of its existing item, rather than silently starting a successor
package. Record any genuinely new obligation as a reviewed catalog amendment.
Do not drop a previously supported input/caller or move a required obligation to
another stage merely to make this catalog green. Scientific changes retain their
separate alignment requirement.
